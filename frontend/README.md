# Abyssinia Academy — Public Website

Static multi-page site (Vite) for the high school platform.

## Pages

- `/` Home
- `/feature.html` Feature
- `/about.html` About
- `/blogs.html` Blogs
- `/contact.html` Contact
- `/pricing.html` Pricing

## Run

```bash
npm install
npm run dev
```

API base: `VITE_API_BASE_URL` (default `http://localhost:5000/api/v1`)

Requires the backend at `../high-school-website-backend/backend`.
